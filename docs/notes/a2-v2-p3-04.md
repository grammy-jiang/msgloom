# A2 v2 semantics P3-04: Outlook native grouping (PROVISIONAL)

Code: `msgloom/a2_kedro/semantics/outlook_grouping.py`.
Tests: `tests/a2_kedro/test_p3_04.py`, `tests/a2_kedro/test_p3_04_bounds.py`.
Builds on P3-01 (`relations.py`) and P3-02 (`relation_safety.py`).

Function: `group_outlook_messages(Sequence[OutlookMessage]) -> OutlookGrouping`.
It is pure. All names and limits are PROVISIONAL.

## Rules

- Native evidence gives CANDIDATE groups only: `conversation_id`, the 22-byte
  `conversation_index` header, `In-Reply-To`, `References`.
- An edge never crosses a workset or a scope (scope kind and scope ID).
- A subject is never evidence. Same-subject messages in different groups give
  a `SubjectHint` (message IDs only, `can_merge` is always `False`).
- A conflict replaces a merge. Codes: `conflicting_parents`,
  `parent_mismatch`, `duplicate_message_id`,
  `conversation_id_across_scopes`, `contradictory_conversation_id`.
- A message with no usable edge is listed in `unresolved` with
  `no_native_evidence`. A missing field is never a match.
- Same conversation ID in two worksets is not reported at all, so no
  cross-workset association leaks.

## Bounds

1024 messages per call, 32 IDs per reference list (both fail closed with a
fixed error text), 256 hints, 16 members per hint (cut, then
`hints_truncated`).

## Limitations

- `conversationIndex` child blocks are not decoded. Only the header is used.
  Code: `msgloom/a2_kedro/semantics/outlook_index.py`. Per MS-OXOMSG the first
  header byte must be `0x01` and the 16-byte GUID must not be all zero.
  Otherwise the index is unusable (`invalid_conversation_index`).
- Parent mismatch compares the last `References` ID to `In-Reply-To`. A client
  that trims `References` is flagged, not merged.
- A message withdrawn by `conflicting_parents` or `parent_mismatch` is not
  placed in any group. It is listed in `unresolved` with the new reason
  `withdrawn_by_conflict`, so its other evidence (for example a valid
  `conversation_id`) is not silently lost. A `duplicate_message_id`
  withdrawal still leaves the conflict as the only trace.
- Messages with no usable edge appear in `unresolved`, not in a separate list.
- Provider-side `conversationId` reuse across mailboxes is flagged only inside
  one workset.

## Errors

A reference list above 32 IDs raises a pydantic `ValidationError` that wraps
a fixed `A2ContractError` text. It does not raise `A2ContractError` directly.
Only the message count bound raises `A2ContractError` directly. The same
wording issue exists in the docstring of
`msgloom/a2_kedro/semantics/relation_safety.py` (line 64). That file is out
of scope here. Fix it later.
