## Remaining P1 (documentation quality; fix before assigning tasks)

**P1-1. Core Kedro nodes have no owning task, and there is no K-stage-to-task map.**
- K-codes appear in the execution plan only at exec:188 (P1-01, topology) and exec:261 (E0-02, integration). C0-07 (exec:151) only defines the `prepared@2` and manifest contracts.
- Nothing builds `prepared@2` from the parse, zone and relation outputs (K6), and nothing builds `a2_result_manifest@1` (K10). The K1/K2 and K11 node wrappers are ambiguous.
- P1-01 depends only on C0-20c, so it would be written before any node function exists. E0-02 (20 minutes) would silently absorb the central assembly step.
- Fix: add a K0–K11 → task table, with explicit tasks and dependencies for K6, K10, the K1/K2 split and K11. Make P1-01 and E0-02 depend on them.

**P1-2. No task edits the dependency lock.**
- The 151 tasks' `edit_paths`/`owner_files` contain no `pyproject.toml` or `uv.lock` (grep returns 0). Handoff:112 protects both files "unless owner".
- F0-09 (JSON:889-929, exec:134) is described as producing a candidate dependency PR, but its only edit path is a docs note.
- P1-01 through P1-13 import Kedro and are gated only by `F0_PRODUCTION_ADMISSION`, not downstream of any lock-changing task.
- Fix: add a lock-owner task for `pyproject.toml`, `uv.lock` and the audit policy, depending on F0-09 plus the gate. Make P1-01/02 depend on it.

**P1-3. The manifest contradicts itself on file ownership.**
- The authority should be `edit_paths`/`owner_files`. They agree with exec and DAG.md in every task I sampled.
- `observable_expected_delivery` and `verify` disagree with them in many tasks:
  - JSON:586: F0-03 delivers `scripts/research/f0_catalog_guard.py` and `...catalog-security.md`. Its edit path is `...f0-dataset-security.md`.
  - JSON:2085: C0-17a delivers the wildcards `contracts/*.py, persistence/a2_*.py`. Its edit path is `triage_input/models_v2.py`.
  - JSON:2257: C0-18 carries the same wildcard text.
  - JSON:2309 and JSON:2406: C0-19 and C0-20b deliver test files other than the ones they own.
  - JSON:3142: P2-01 delivers `parsing/mime_html.py`. Its edit path is `parsers/`.
  - JSON:3035, 3099 and 3560: P1-12b, P1-13 and P2-10 deliver files with names different from their edit paths.
  - JSON:912: F0-09 delivers a `docs/plans/` checklist, not its docs note.
- 93 `verify` lines say "Create/check: tests/a2_kedro/test_<id>.py". Eight tasks list such a file in their own `edit_paths`/`owner_files`; the rest do not.
- One of those lines is on the read-only reviewer task P1-13 (JSON:3105).
- A manager following these fields would make workers edit outside their allowlist, which handoff:88 forbids.
- Fix: regenerate those fields from `edit_paths`, add a precedence statement to the manifest header, and either add test paths to the owned files or drop the lines.
